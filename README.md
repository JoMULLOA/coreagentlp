# Tentaculus — Landing Page

Landing page oficial de presentación y conversión para la plataforma SaaS **Tentaculus** (WhatsApp AI Ops para Empresas).

## 🚀 Despliegue en Vercel

Este proyecto está 100% optimizado para desplegarse en **Vercel** en 1 clic:

1. Sube este directorio a tu repositorio de GitHub (o importa el repositorio en Vercel).
2. En el panel de Vercel, selecciona el framework **Next.js** (se detectará automáticamente).
3. Haz clic en **Deploy**.

## 🛠️ Ejecución Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev
```

La landing page estará disponible en `http://localhost:3000`.

## 📄 Páginas Incluidas

- `/` — Landing Page principal (Hero interactivo, Simulador WhatsApp, Funcionalidades, Verticales, Arquitectura, Planes y FAQ).
- `/terms` — Términos y Condiciones completos de servicio SaaS.
- `/privacy` — Política de Privacidad y tratamiento de datos de WhatsApp.
